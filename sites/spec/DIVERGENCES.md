# Raku++ / Rakudo divergences

Generated by `tools/divergences.raku` from the behaviour matrix: every operator
run against the same battery of operand types on both interpreters. Rows where
both engines reject the expression count as agreement, however differently they
word the diagnostic — only value-vs-value differences and accept-vs-reject are
listed. Every entry is a Raku++ fix candidate.
