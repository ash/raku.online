Raku++

The interpreter behind everything on this site. An independent implementation of Raku, written from scratch in C++17 and compiled to WebAssembly, so it runs in a browser tab with nothing behind it. 

say "Raku++ is running this, in your browser.";
say (1..10).grep(*.is-prime).join(', ');

Why a second implementation?

Rakudo is the reference implementation and it is excellent, but it needs installing, and it does not run in a browser. Raku++ trades completeness for reach: a smaller, faster-starting interpreter that someone can use without downloading anything. That is what makes the playground, the tour and the drills possible at all.

It is not a drop-in replacement, and this site does not pretend otherwise. Where Raku++ and Rakudo disagree, the specification says so on the page for that feature, in as many words.

Running it outside a browser

Raku++ is a native binary as well. The rakupp repository has the source and releases; this very site is generated by it.
