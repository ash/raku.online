Where next

You've seen the core of the language — here's one last program and where to go from here.

That's the tour: values, control flow, data structures, functions with real signatures, classes, roles, regexes, grammars, and junctions. One last program, using a little of everything:

for 1..15 {
    say $_ %% 15 ?? 'FizzBuzz'
     !! $_ %% 3  ?? 'Fizz'
     !! $_ %% 5  ?? 'Buzz'
     !! $_;
}
