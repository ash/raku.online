Control flow · lesson 5 of 18

Conditionals

Branch with if/elsif/else and unless — no parentheses needed around the condition.

if runs a block when its condition is true. No parentheses are required around the condition:

my $temperature = 35;
if $temperature > 30 {
    say 'A hot one.';
}
elsif $temperature > 15 {
    say 'Pleasant.';
}
else {
    say 'Bring a jacket.';
}
Output
A hot one.

unless is if not — handy when the negative reads more naturally. It takes no else.

my $logged-in = False;
unless $logged-in {
    say 'Please sign in.';
}
Output
Please sign in.

Notice the variable name: identifiers in Raku may contain hyphens — $logged-in is one name, and reads like English.

The ternary and statement modifiers #

?? !! picks between two expressions; and a statement modifier puts the condition after the statement, which is pleasant for one-liners:

my $n = 7;
say $n %% 2 ?? 'even' !! 'odd';
say 'lucky!' if $n == 7;
Output
odd
lucky!
