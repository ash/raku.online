Embed Raku

Raku inside the things you already use: your web page, a WordPress blog, an Excel or Google Sheets spreadsheet. The engine is WebAssembly and runs where the page or the spreadsheet runs: no server, no account, and nothing is sent anywhere.

Web pageOne script tag turns code on your page into a real, running Raku editor.
WordPressThe Raku Snippets plugin: code blocks in your posts that readers can edit and run.
Excel=RAKU.EVAL formulas: exact decimals, integers of any size, regexes and grammars on the text in your cells.
Google SheetsThe same formulas as =RAKU, through a script attached to the spreadsheet.

On a web page #

Load the script anywhere in the page, and mark the code with data-raku. Nothing to install, no build step, no npm. 

<script src="https://raku.online/raku.js"></script>

<pre data-raku>say "Hello from an embedded editor!";</pre>

That markup renders this — go ahead and change it:

say "Hello from an embedded editor!";

Raku on a web page has the rest: code blocks you already have, every option, hiding parts of the editor, your own colours, and serving the three files yourself.

On WordPress #

  1. Download raku-snippets.zip.
  2. In WordPress, go to Plugins → Add New → Upload Plugin, choose the zip, then Install Now and Activate.
  3. In a Code or Preformatted block, open Advanced and type raku into Additional CSS class(es).

That block now runs, and the script is loaded only on the posts that need it. Raku on WordPress has the details.

In Excel #

The Raku add-in gives Excel one more function, =RAKU.EVAL. The code comes first; $^a, $^b, … are the values after it, in order, and @_ is all of them, ranges flattened into their cells. 

=RAKU.EVAL("($^a - $^b) + 1", 43.1, 43.2)

This is exactly 0.9. Excel itself works in doubles, and its own =(43.1-43.2)+1 shows 0.899999999999999. Raku's decimals are exact rationals, its integers have no size limit, and its regexes and grammars work on the text in your cells.

  1. Download the add-in's manifest, manifest.xml.
  2. Load it into Excel (Microsoft calls this sideloading):
    • Excel on the web: open the Add-ins dialog, choose Upload My Add-in and pick the file (how).
    • Excel for Mac: copy the file into ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/, making the folder if it is not there, and restart Excel. Then choose Home → Add-ins and pick Raku formulas from the menu (how).
    • Excel for Windows: put the file in a shared folder and add that folder under File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs (how).
  3. Click the Raku button on the Home tab, once. That starts the add-in for the first time, which is when Excel registers =RAKU.EVAL, for you and every workbook from then on. Until then a formula shows #NAME?, and a cell that already does keeps it until you enter the formula again. The pane that opens has examples to insert.
  4. Type =RAKU.EVAL( in a cell.

The add-in's files come from raku.online; the formulas run inside Excel and send your data nowhere. The guide covers the rest: values in and out, your own subs on a sheet named Raku, and the limits.

In Google Sheets #

The same formulas, spelled =RAKU, with the same exact answers: 

=RAKU("($^a - $^b) + 1", A1, A2)

In Sheets the engine runs inside an Apps Script attached to the spreadsheet, which also adds a Raku menu. For now that script is added from the guide: build it with Raku++ and upload it with Google's clasp, or paste its files into Extensions → Apps Script.
