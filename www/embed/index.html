Embed Raku

Raku inside the things you already use: your web page, a WordPress blog, an Excel or Google Sheets spreadsheet. The engine is WebAssembly and runs where the page or the spreadsheet runs — no server, no account, and nothing is sent anywhere.

Raku on a web page

One script tag, and any block marked data-raku — or every Raku code block already on the page — becomes an editor with a Run button.

Raku on WordPress

The Raku Snippets plugin: give a code block the class raku, and readers can edit and run it in the post.

Raku in Excel and Google Sheets

Formulas in Raku: =RAKU.EVAL("($^a - $^b) + 1", 43.1, 43.2) is exactly 0.9, integers have no size limit, and regexes work on the text in your cells.
