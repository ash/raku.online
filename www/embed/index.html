Embed Raku

Raku inside the things you already use: your web page, a WordPress blog, an Excel or Google Sheets spreadsheet, a phone app. On the web the engine is WebAssembly; in an app it is native code. Either way it runs where the page, the spreadsheet or the app runs — no server, no account, and nothing is sent anywhere.

Raku on a web page

One script tag, and any block marked data-raku — or every Raku code block already on the page — becomes an editor with a Run button.

Raku in Excel and Google Sheets

Formulas in Raku: =RAKU.EVAL("($^a - $^b) + 1", 43.1, 43.2) is exactly 0.9, integers have no size limit, and regexes work on the text in your cells.

Excel · Google Sheets

Raku in a mobile app

The engine compiled into an iOS or Android app: Raku programs run on the phone as native code, with threads and deep recursion, through the same C API as every other host.
