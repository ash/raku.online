Privacy policy

Raku formulas: the Excel add-in and the Google Sheets add-on that add =RAKU.EVAL to Excel and =RAKU to Sheets, made by Andrew Shitov. This policy also covers the Sheets script you can paste into a spreadsheet yourself. Last changed on 8 October 2026.

In short #

The formulas compute where the spreadsheet runs. Raku formulas collect nothing, keep nothing outside your spreadsheet, and send your data to no one: not to the developer, and not to anyone else. There are no accounts, no cookies, no analytics and no advertising.

What they read and write #

  • The code and the values of each RAKU formula, to compute its result.
  • Column A of a sheet named Raku, when there is one: the subs a formula can call.
  • They change the spreadsheet only when you ask. Add the Raku sheet inserts that sheet, with two examples on it; Recalculate RAKU formulas takes each RAKU formula out and puts it back, so that it runs again.

Nothing else in the spreadsheet, and no other file.

Where the computing happens #

Excel. On your computer, inside Excel, or in your browser for Excel on the web. When the add-in starts, Excel downloads its program files from raku.online and Microsoft's Office.js library from Microsoft. These are downloads of program files: no spreadsheet content goes with them.

Google Sheets. In Google Apps Script, Google's environment for Sheets add-ons and scripts, as for every Sheets add-on: a formula's code and values go from the spreadsheet to Apps Script, and the result comes back, all within Google.

What the developer receives #

Nothing from your spreadsheets. The Sheets add-on keeps no log: what a formula prints is discarded, and its error logging is off. The Excel add-in shows what formulas print in its own pane, on your screen only. The Sheets script you paste yourself is yours, and its log is yours too.

Microsoft and Google tell the developer how many people have installed the add-ins, as their stores do for every add-in, and Google's Apps Script dashboard shows how many times the add-on ran and how long it took. None of it holds spreadsheet content.

Hosting #

raku.online, where the Excel add-in's files are, is hosted by GitHub Pages. GitHub may record the IP address of whoever downloads a file from it, for security, as the GitHub General Privacy Statement describes. raku.online itself has no analytics and sets no cookies.

Google user data #

The Sheets add-on asks Google for one permission: to see and change the spreadsheet it is used in (the spreadsheets.currentonly scope). It uses it only as this page describes, keeps none of the data, and passes none of it on. Raku formulas' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
